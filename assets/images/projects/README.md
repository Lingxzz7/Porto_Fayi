# Foto project

Simpan foto karya di folder ini dengan nama berikut. Kartu project akan menampilkan **Coming Soon** selama fotonya belum tersedia. Setelah file dengan nama yang sesuai ditambahkan, foto tampil otomatis dan label Coming Soon hilang.

- `poster-design-01.jpg` sudah terpasang; tambahkan `poster-design-02.jpg` dan `poster-design-03.jpg`
- `ui-web-design-01.jpg` sampai `ui-web-design-03.jpg`
- `logo-design-01.jpg` sampai `logo-design-03.jpg`
- `social-media-design-01.png` sampai `social-media-design-03.png` sudah terpasang

Kalau file fotonya memakai format lain, ubah ekstensi pada atribut `src` di `projects/index.html` agar sesuai.
